# Owl & Compass — Build Context

## Architectural Decisions
- **Pydantic v2 Contracts:** Strict model validation for `VerifiedObservation` requiring non-empty `evidence_urls` array to enforce Zero Hallucination policy at schema level. Added resilient Pydantic field validators (`normalize_short_text`, `ensure_minimum_questions`, `normalize_summary`) to automatically pad/supplement short LLM text outputs without crashing ingestion pipelines.
- **RRF Hybrid Search:** `hybrid_workspace_search` combines PostgreSQL full-text search (`tsvector`) and cosine distance (`pgvector`) using Reciprocal Rank Fusion (`rrf_k = 60`).
- **Map-Reduce Ingestion Pipeline:** `normalize_touchpoint_input` enforces a 50,000 character maximum payload limit and splits inputs into ~4,000 character chunks (hard sub-chunking long lines $\le 4,000$ chars). `extract_touchpoint_entities` executes bounded parallel extraction using `asyncio.Semaphore(5)` with chunk fault tolerance (`return_exceptions=True`), explicit total failure error handling, and entity deduplication. `append_timeline_event` is an async function sorting events sequentially by document offset in memory and using `await asyncio.sleep` backoff to prevent blocking the event loop.
- **Discovery Agent XML Guardrails:** Input scraped HTML pages are cleaned of scripts, styles, and markup tags via `clean_html_content`. Scraped contents are wrapped inside `<untrusted_web_content>` XML tags in `fetch_web_content`. Schema validation errors and scheme mismatch (e.g. `ftp`) are normalized to `ValueError` at the adapter boundary. Instruction formatter `format_research_prompt` guarantees newline separation between multiple XML blocks and appends a mandatory `Web Content Guardrail Enforcement` security policy to ensure LLMs treat untrusted contents strictly as passive data and never execute prompt injection commands embedded inside. URL deduplication in `deduplicate_sources` normalizes subdomains (stripping `www.`), schemes, trailing slashes, and parameters.
- **Next.js App Router Frontend:** Standard App Router layout in the `/web` subdirectory. Client-side dashboard component `FounderDashboard.tsx` binds to Next.js Server Actions `createFounder`, `saveTouchpoint`, and `generatePrepBrief` to mutate state and retrieve research briefs. Input validations in server actions sanitize HTML tags, protect against comment syntax exploits, and enforce field length limitations to guarantee security. Persisted local storage via `mock-db.json` file writes maintains state across page loads and node process cycles when Supabase variables are absent. Higher contrast text themes ensure compliance with WCAG AA guidelines.
